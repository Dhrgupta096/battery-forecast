1. Linear Regression Model & Normal Equations

For sequential discharge-cycle index k = 1, 2, ..., n_train, discharge capacity is modeled as Q̂(k) = β0 + β1 k. With design matrix X = [[1, k1], ..., [1, kn]], least-squares coefficients solve (XᵀX)β = Xᵀy via explicit Gaussian Elimination (REF) and Gauss–Jordan Elimination (RREF).

2. Cycle-Based & Recorded-Timestamp RUL

Given End-of-Life threshold Qeol (default 1.4 Ah, 30% fade from 2.0 Ah rated capacity) and training cutoff cycle kc:

  • Predicted crossing cycle: k* = (Qeol - β0) / β1 (for β1 < 0).
  • Cycle RUL: RULcycles = k* - kc.
  • Time RUL (Primary Median Cadence): RULhours,med = RULcycles × Δtmed, where Δtmed is the median positive time interval between consecutive training discharges.
