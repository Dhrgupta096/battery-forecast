Interactive research simulation for undergraduate aerospace engineering:
1. **Linear-regression capacity forecasting** ($\hat{Q}(k) = \beta_0 + \beta_1 k$) fit exclusively on chronological training observations.
2. **Transparent normal-equation solvers** using hand-written Gaussian elimination (REF + back-substitution) and Gauss–Jordan elimination (RREF), verified against QR/SVD least squares (`numpy.linalg.lstsq` and `scikit-learn`).
3. **Remaining Useful Life (RUL) in discharge cycles** relative to an adjustable experimental End-of-Life threshold (default $1.4\text{ Ah}$, corresponding to $30\%$ fade from $2.0\text{ Ah}$ rated capacity), with explicit safeguards against non-negative slopes, pre-cutoff crossings, and unreached thresholds.
4. **Time-based RUL from actual recorded timestamps** using the median positive inter-discharge training interval (primary) and mean interval (pause-sensitivity comparison), with IQR and range diagnostics.
5. **Held-out threshold-crossing validation** comparing predicted crossing cycles and timestamps against actual observed crossings in the held-out test set across all **34 unique NASA PCoE cells** (with identical duplicate `.mat` archives excluded via MD5 verification).
6. **3D Orbital View & Fleet Simulation** propagating real CelesTrak GP/TLE satellite elements via SGP4 (`satellite.js`) with LEO / MEO / GEO / HEO filtering and hypothetical eclipse-cycle battery projections.

## Project Structure

| File / Folder | Purpose |
| :--- | :--- |
| `core.py` | Official NASA `.mat` extraction, chronological split, design matrix, Gaussian (REF) and Gauss–Jordan (RREF) solvers, and held-out error metrics |
| `rul_analysis.py` | Column alias detection, dataset quality audit, cycle RUL & safeguards, recorded-timestamp cadence statistics, held-out crossing validation, `B0005` reproducibility check, 34-battery MD5 deduplication, and satellite fleet analysis |
| `app.py` | Streamlit dashboard (Forecast & RUL, RUL & Cadence Validation, Data & Quality Audit, Matrix Solver, Residuals & Checks, Cross-Battery, Orbital View, Methodology & Paper, Results & Export) |
| `globe.html` | Interactive 3D WebGL Earth (`globe.gl` + `satellite.js`) with real-time SGP4 propagation and LEO/MEO/GEO/HEO filtering |
| `research_summary.md` | Research-paper-ready methodology, provenance, equations, empirical tables, and limitations |
| `check_core.py` | Automated verification suite (exits non-zero on any failure) |
| `data/nasa_pcoe_discharge_capacity.csv` | Extracted full-precision discharge series for primary cells `B0005`, `B0006`, `B0007`, and `B0018` (636 rows) |
| `data/nasa_pcoe_all_34_batteries.csv` | Extracted full-precision discharge series for all 34 unique NASA PCoE batteries (2,769 rows) |
| `data/nasa_pcoe_deduplication_log.csv` | Audit log of the 4 identical MD5 duplicate `.mat` files (`B0025`–`B0028`) skipped during archive extraction |
| `outputs/` | Reproducible derived CSV tables generated by `check_core.py` |
